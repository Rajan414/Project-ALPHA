# Antipink Frontend

Antipink is a mobile-first Android-style frontend prototype for a media downloader app. It includes:

- Paste/share link entry
- Source type chips for video, music, and images
- Quality choices for 4K, HD, and MP3
- Simulated fast download queue
- Android share-target concept screen
- Downloads library and preferences screens

This is frontend only. A production app still needs a compliant backend/download engine, Android share intent integration, storage permissions, and source-specific rules that respect media rights and platform terms.

Open `index.html` in a browser to preview the prototype.
